## CCM
CCM это программа для предсказания следующего слова на основе входных данных.
Это улучшеная цепь маркова для предсказания следующего слова с выборкой слов исходя от контекста или на основе похожего контекста в входных данных.

## ChatCCM
По своей сути это тот же CCM но только в качестве входных дынных передаётся примеры диалога в нужном формате.
### Пример:
```
user: hello
assistant: hello, how can i help you?
```

## Где можно использовать?
Этот алгоритм можно использовать в разных отрослях таких как:
1. Видеоигры - чат с неигровым персонажем
2. Чат боты - простые чат боты
3. Клавиатуры - в качестве более продвинутых подсказок в клавиатурах на телефонах

## Какие плюсы и минусы перед нейросетью?
Плюсы:
1. Не требует обучения, работает сразу
2. Полная открытость процессов
3. Поддержка динамического изменение датасета

Минусы:
1. Может долго работать на больших датасетах
2. Сокращает текст
3. Не всегда следует по датасету

## Как желательно составлять данные для CCM
Так как CCM может долго работать при больших обьёмах данных будет желательно разграничить знания и активную базу.
Будет желательно воспользоватся возможностью динамического изменения датасета чтобы подгрузить нужные знания перед генерацией. 
### Пример:
Активная база:
```
user: hello
assistant: hello, how can i help you?
```
База знаний:
```
user: capital of France
assistant: Paris
```
Если выполняется запрос
> hello

Мы не будем подгружать из базы знаний

В противном случае если запрос 
> capital of France

Мы подгрузим из базы знаний запрос

## Может ли алгоритм сгенерировать что-то новое?
Я не знаю точного ответа так как алгоритм несколько раз выдавал граматически правельные склейки нескольких ответов для ответа на неизвестный вопрос но он не часто так делает. Если у вас произошло такое следует проверить данные которые подаются на вход.

## Входные данные
Входные данные должны быть представлены в виде листа примеров. Если примеры будут не в виде листа то тогда программа будет выдавать один и тот же ответ на все запросы.
